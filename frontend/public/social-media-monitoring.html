Facebook Monitoring

Ang Facebook ay hindi pwedeng i-embed sa loob ng kahit anong website (harang ito ng Meta mismo), kaya ang mga button sa ibaba ay nagbubukas ng sariling FB window — doon ka maglo-log in nang isang beses, at mananatili ang login sa mga susunod na pagbukas.

Susunod na yugto (kapag napagdesisyunan): (B) ikonekta ang FB Pages bilang Chatwoot inboxes para ang Messenger ay kusang dumaloy sa Customers page kasama ng handoff/CSAT/reply — o (C) diretsong Meta API integration para makita dito mismo ang comments at mentions kada brand.
